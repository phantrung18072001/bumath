The user must complete these steps in the browser. Claude cannot do these — they require dashboard authentication.

**Part A: Supabase project (skip if already exists)**

1. Go to https://supabase.com and sign in
2. Click "New Project"
3. Choose organization, name it "bumath", select a region close to Vietnam (e.g., Singapore), set a database password
4. Wait for project to provision (~2 minutes)
5. Go to **Project Settings > API** and copy:
   - **Project URL** (looks like `https://xxxx.supabase.co`)
   - **anon public key** (starts with `eyJ...`)

**Part B: Update local .env.local**

Replace the placeholder values in `.env.local` with real values:
```
VITE_SUPABASE_URL=https://your-real-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...your-real-anon-key
```

**Part C: Connect repo to Vercel**

1. Go to https://vercel.com and sign in with GitHub
2. Click "Add New... > Project"
3. Import the `bumath` GitHub repository
4. Framework Preset: Vite (should auto-detect)
5. Build Command: `yarn build` (should auto-detect)
6. Output Directory: `dist` (should auto-detect)
7. **Before deploying**, expand "Environment Variables" and add:
   - `VITE_SUPABASE_URL` = the Project URL from step A5
   - `VITE_SUPABASE_ANON_KEY` = the anon key from step A5
8. Click "Deploy"
9. Wait for deployment to complete
10. Note the production URL (e.g., `bumath.vercel.app` or `bumath-xxx.vercel.app`)

**Part D: Disable GitHub Pages (optional but recommended)**

1. Go to GitHub repo Settings > Pages
2. Set Source to "None" or disable Pages
3. This prevents the stale GitHub Pages site from confusing users
