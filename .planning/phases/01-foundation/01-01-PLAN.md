```bash
yarn add @supabase/supabase-js@2.78.0
```

Use `yarn`, not `npm`. The pin to 2.78.0 is required because v2.79+ dropped Node 18 support and this project runs Node 18.20.8.

**Step 2: Create `src/lib/supabase.ts`** with this exact content:

```typescript
import { createClient } from '@supabase/supabase-js'

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY

export const supabase = createClient(supabaseUrl, supabaseAnonKey, {
  auth: {
    persistSession: true,
    autoRefreshToken: true,
    detectSessionInUrl: true,
  },
})
```

This is the singleton pattern from the official Supabase React quickstart. All future phases import `supabase` from this single file. Never call `createClient()` anywhere else.
