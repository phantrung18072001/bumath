## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline icon-to-text gap (e.g. `gap-1`) |
| sm | 8px | Compact element spacing, between badge items (`gap-2`) |
| md | 16px | Default element spacing, card inner padding |
| lg | 24px | Section padding, dialog section gaps |
| xl | 32px | Layout gaps, page top/bottom padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical spacing |

Exceptions:
- Touch targets: all interactive buttons use `min-h-[48px]` — established pattern in Phase 02+
- Admin sidebar nav items: `py-2.5` (10px vertical) — matches existing AdminLayout.tsx pattern
- Admin page container: `px-4 py-8` — matches CoursesPage.tsx pattern

Source: Existing admin pages (CoursesPage.tsx, UsersPage.tsx, AdminLayout.tsx), CLAUDE.md pre-delivery checklist

## UI Surfaces — Component Inventory

### Surface 1: `/quan-tri/goi-hoc` — Admin Package Management Page

Pattern: Identical to `/quan-tri/khoa-hoc` (CoursesPage.tsx). Decision D-11.

**Layout:**
- `<AdminLayout>` wrapper (sidebar + main content area)
- `container mx-auto px-4 py-8` page container
- Page h1: "Quản lý gói học" — `text-xl font-semibold leading-[1.3]`
- Header row: h1 left + "Tạo gói học" primary button right (`min-h-[48px]`)

**Toolbar (below header):**
- Search input with leading Search icon — `placeholder="Tìm theo tên gói học…"`
- No grade filter for package list (packages define grades, not filtered by them)
- Count label: `{n} gói học` (text-sm text-muted-foreground)

**Table columns:**
| Column | Content |
|--------|---------|
| STT | Row number (1-indexed, text-muted-foreground) |
| Tên gói học | Package name (font-normal) |
| Giá (VND) | Price formatted as Vietnamese VND (e.g. "1.500.000 ₫") — text-sm |
| Lớp phủ | Grade coverage badges (1–4 badges using GRADE_BADGE palette) |
| Hành động | Edit button (Pencil icon, outline variant, min-h-[48px]) + Delete button (Trash2 icon, destructive outline) |

**States:**
- Loading: 5× `Skeleton` rows `h-10 w-full rounded-md`
- Empty (no packages): heading "Chưa có gói học nào" + body "Nhấn 'Tạo gói học' để bắt đầu." + inline CTA button
- Empty (after search): heading "Không tìm thấy kết quả" + body "Thử thay đổi từ khóa."

**PackageFormDialog** (Create/Edit):
- `DialogContent` `max-w-lg`
- Form fields:
  - Tên gói học: Input, required
  - Mô tả (tùy chọn): Input
  - Giá (VND): Input type=number, required, `placeholder="1500000"`
  - Lớp phủ: 4 Checkbox items in a grid (2×2) — one for each grade value. Labels use GRADE_BADGE labels. At least one grade required.
- Footer: "Hủy" (ghost/cancel) + "Lưu gói học" / "Cập nhật gói học" (primary)

**Delete confirmation:** AlertDialog — title "Xóa gói học", description warns about student impact, actions "Hủy" + "Xóa" (destructive).

**Empty state (no packages):**
- Heading: "Bạn chưa có gói học nào"

**Loading skeleton:** 1 identity card skeleton + 2 package card skeletons

## Interaction Contracts

### Transitions and Animation
- All button hover/active states: `transition-colors` at 150ms (Tailwind default) — established pattern
- `bm-clay-card-student` hover: `translateY(-2px)` at 200ms ease — for package cards that are NOT clickable, remove hover transform (add `cursor-default` override)
- Page navigation: instant (React Router client-side)
- Dialog open/close: Radix Dialog built-in animation (fade + scale, ~150ms)
- Toast notifications: Sonner library, auto-dismiss after 4s

### Focus States
- All interactive elements must have visible focus ring via `focus-visible:ring-2 focus-visible:ring-ring` (shadcn default)
- Checkbox group in PackageFormDialog: keyboard navigable, Enter/Space toggles

### Responsive Breakpoints
| Breakpoint | Width | Behavior |
|------------|-------|----------|
| Mobile | 375px | Single column layout; admin sidebar hidden (not implemented in AdminLayout yet — out of scope for Phase 14) |
| Tablet | 768px | Student profile: single column cards |
| Desktop | 1024px | Admin table full columns visible |
| Wide | 1440px | Constrained by `container max-w-[1400px]` |

## Price Formatting

Price displayed as Vietnamese VND throughout admin UI (display only, no payment processing):

```typescript
// Format: 1500000 → "1.500.000 ₫"
const formatVND = (amount: number) =>
  new Intl.NumberFormat('vi-VN', { style: 'currency', currency: 'VND' }).format(amount)
```

- Admin package table: formatted string in table cell
- Admin PackageFormDialog: raw number input, hint text "Nhập số tiền bằng VND (ví dụ: 1500000)"
- Student profile package card: formatted string, label "Giá:" prefix
- If price_vnd is 0: do not display price line on student profile card
