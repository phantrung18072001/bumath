## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact list item padding, button icon gap |
| md | 16px | Card body padding, form field spacing, sidebar item padding |
| lg | 24px | Section vertical padding, card gap in grid |
| xl | 32px | Layout column gap (sidebar + content), page vertical rhythm |
| 2xl | 48px | Major section breaks, StudentLayout header height |
| 3xl | 64px | Page-level top/bottom margin on desktop |

Exceptions:
- All interactive tap targets (buttons, lesson list items, tab triggers): minimum 48x48px — satisfies UX-02 and mobile 375px requirement (from REQUIREMENTS.md UX-01, UX-02 and CONTEXT.md D-06)
- YouTube embed aspect ratio: `aspect-video` (16:9, Tailwind class) — not a spacing token but a layout constraint
- Sidebar fixed width: 280px on desktop; collapses to full-width tab panel on mobile

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (text-base) | 400 (regular) | 1.5 | Lesson description text, sidebar lesson titles, submission status text |
| Label | 14px (text-sm) | 600 (semibold) | 1.4 | Badge labels (Lớp 7/8/9/Ôn chuyên), form field labels, sidebar chapter headings, breadcrumb text |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Lesson title in content panel, course card name, page section headings |

Rules:
- Maximum 2 weights in any single view: 400 (body content) + 600 (labels/headings). Display weight 700 applies only to page-level titles.
- Vietnamese text renders correctly at all declared sizes with "Be Vietnam Pro" — no fallback needed for THCS diacritics.

## Color

CSS variables defined in `src/index.css`. All values are HSL. Resolved hex approximations shown for reference.

| Role | CSS Variable | Resolved Value | Usage |
|------|-------------|----------------|-------|
| Dominant (60%) | `--background` | hsl(30 50% 98%) ≈ #FDFAF7 | Page background, StudentLayout background, content panel background |
| Secondary (30%) | `--card` / `--sidebar-background` | hsl(0 0% 100%) / hsl(0 0% 98%) ≈ #FFFFFF / #FAFAFA | Course cards, sidebar panel, StudentLayout header strip |
| Accent (10%) | `--primary` | hsl(24 95% 53%) ≈ #F97316 (orange) | See reserved list below |
| Destructive | `--destructive` | hsl(0 84% 60%) ≈ #EF4444 | No destructive actions in Phase 4 — color available but not used |

**Accent (`--primary` orange) reserved exclusively for:**
1. "Đánh dấu đã xem" button (primary variant, before marking complete)
2. Active/selected lesson row highlight in the sidebar tree (left border accent stripe)
3. Progress bar fill (uses shadcn `<Progress>` which inherits `--primary`)
4. "Nộp bài" (submit photo) button — primary variant only while submission is allowed

**Secondary semantic colors used for status badges:**
- Grade badges use semantic tints (from Phase 3 established pattern in `CoursesPage.tsx`):
  - Lớp 7: `bg-blue-100 text-blue-700`
  - Lớp 8: `bg-green-100 text-green-700`
  - Lớp 9: `bg-purple-100 text-purple-700`
  - Ôn chuyên: `bg-orange-100 text-orange-700`
- Submission status badges (shadcn `<Badge>` with custom className):
  - "Chưa nộp": `bg-slate-100 text-slate-600` (neutral, no action pressure)
  - "Đã nộp (đang chờ chấm)": `bg-blue-100 text-blue-700` (informational, waiting)
  - "Đã chấm": `bg-green-100 text-green-700` (completed)
- Lesson sidebar status icons:
  - ✓ (completed): `text-green-600`
  - → (active/current): `text-primary` (orange accent)
  - ○ (not started): `text-muted-foreground` (grey)

Source: `src/index.css` for CSS variables; `CoursesPage.tsx` for badge color pattern.

## Layout Contracts

### StudentLayout (new component — `src/components/student/StudentLayout.tsx`)

- Fixed header: height 48px minimum, `bg-card border-b border-border`
- Header content: logo (left) + student display name (center or left) + "Đăng xuất" button (right, ghost variant, 48px touch target)
- Body: full viewport height minus header, `bg-background`
- No marketing nav links — separate from the existing marketing `<Header>` component (D-04, D-05)

### /courses — Course Listing Page

- Layout: single column, max-width `container` (1400px, Tailwind `container` class)
- Page heading: "Khóa học của tôi" — 28px, weight 700
- Grid: `grid grid-cols-1 gap-6 sm:grid-cols-2` — 1-col mobile, 2-col desktop (D-02)
- Each card: `<Card>` with 16px padding, course name (heading 20px semibold), grade badge, progress bar + "X% hoàn thành" label
- Progress bar: `<Progress value={completionPercent} className="h-2 mt-2" />`

### /courses/:courseId — Course Detail Page (Desktop)

- Layout: `flex flex-row h-[calc(100vh-48px)]`
- Sidebar (left): fixed 280px width, `bg-sidebar border-r border-sidebar-border`, `<ScrollArea>` for overflow
  - Chapter sections via `<Accordion type="multiple">` (all expanded by default)
  - Lesson items: 48px min-height, 16px padding, icon (✓/→/○) + lesson title, active lesson gets `bg-sidebar-accent` background and primary left border `border-l-2 border-primary`
- Content area (right): flex-1, `overflow-y-auto p-8`
  - Section order (top to bottom): YouTube embed → lesson description → assignment file → submission area → mark-complete button
  - YouTube embed: `<AspectRatio ratio={16/9}><iframe ... /></AspectRatio>` with rounded-lg
  - `<Separator className="my-6" />` between each section

### /courses/:courseId — Course Detail Page (Mobile, 375px)

- Layout: single column, full width
- `<Tabs defaultValue="content">` at top of page below StudentLayout header
  - Tab "Nội dung": renders content panel (video + description + assignment + submit + mark-complete)
  - Tab "Mục lục": renders sidebar tree (chapters + lessons accordion)
  - Tab switching does not reload data — same query cache (D-06, D-07)
- Tab trigger height: minimum 48px (UX-02)
- Content section: `p-4` (16px) on mobile

## Interaction Contracts

### Marking a Lesson Complete (D-09, D-10, LEARN-04)

- Initial state: Button "✓ Đánh dấu đã xem" — `variant="default"` (primary orange fill), full-width on mobile, auto-width on desktop
- On click: optimistic update — button immediately transitions to "Đã xem ✓" state and becomes `disabled`
- Disabled state: `variant="secondary"`, `opacity-70`, cursor-not-allowed, non-interactive
- Rollback on API error: restore original button state + show toast error "Không thể lưu trạng thái. Vui lòng thử lại."
- The button is always one-way — no unmark (D-10)

### Assignment File Viewer (D-11, LEARN-03)

- Link label: "Đề bài: Xem file" — styled as `<Button variant="outline" size="sm">` with ExternalLink icon (Lucide)
- Behavior: `window.open(url, '_blank', 'noopener')` — opens Supabase Storage URL in new tab
- Visibility: only rendered when `lesson.assignment_path !== null` (D-13)

### Photo Submission (D-12 through D-18, SUBMIT-01 through SUBMIT-04)

**Unsubmitted state:**
- Section heading: "Nộp bài làm" (label 14px semibold)
- Status badge: "Chưa nộp" — `bg-slate-100 text-slate-600`
- Upload control: visually hidden `<input type="file" accept="image/*,image/heic" capture="environment" />`
- Trigger button: "Chọn ảnh bài làm" — `variant="outline"`, Camera icon (Lucide), 48px height
- Selected image preview: `<img>` thumbnail, max 120px height, with filename and size label below
- Compress + upload button: "Nộp bài" — `variant="default"` (primary orange), disabled until image selected
- Loading state during compress + upload: Loader2 spinner inside button, button disabled, label "Đang xử lý..."

**Submitted state (D-15):**
- Status badge: "Đã nộp (đang chờ chấm)" — `bg-blue-100 text-blue-700`
- Submitted image: displayed as thumbnail (max 200px height, cursor-zoom-in for lightbox or new-tab open)
- Submission date: "Đã nộp lúc {date}" — 14px, `text-muted-foreground`
- Upload area is hidden — no resubmission UI (v2 deferred)

**Graded state (shown in Phase 4 read-only; grading done in Phase 5):**
- Status badge: "Đã chấm" — `bg-green-100 text-green-700`
- Score and comment: read-only display (reserved for Phase 5 implementation — Phase 4 sets up the status display structure only)

## Accessibility Contract

- All interactive elements: minimum 48x48px touch target (UX-02, satisfies WCAG 2.5.5)
- YouTube iframe: `title="Video bài học: {lessonTitle}"` attribute required
- File input: associated `<label>` with visible text "Ảnh bài làm"
- Progress bar: `aria-label="Tiến độ hoàn thành: X%"` on `<Progress>`
- Lesson sidebar items: `aria-current="true"` on active lesson
- Loading spinners: `aria-label="Đang tải..."` on Loader2 icon wrappers
- Status badges: use semantic color + text — not color alone (WCAG 1.4.1)
- Disabled "Đã xem ✓" button: `disabled` attribute (not just visual styling) for correct screen reader state
