## Spacing Scale

Standard 8-point scale (project-wide):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Badge padding, chip gap |
| md | 16px | Card padding (mobile), element gap |
| lg | 24px | Section spacing, tab content padding |
| xl | 32px | Card padding (desktop) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets: `min-h-[44px]` (icon buttons) / `min-h-[48px]` (primary actions) — UX-02 rule
- Lesson content area: `p-4 md:p-8` (existing pattern from LessonContent)
- Section label: `text-[11px]` uppercase `tracking-widest mb-3` (existing pattern)

## Color

Student-facing pages (CourseDetailPage context):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Tab content background, cards |
| Page background | `bg-background` (white, `hsl(0 0% 100%)`) | Main content area |
| Secondary (30%) | `hsl(var(--muted))` ≈ `#F5F0EB` | Muted sections, empty states, description bg |
| Accent (10%) | `#F97316` (`--primary`) | Active tab underline, upload CTA, progress button |
| Border | `hsl(var(--border))` | Card borders, tab dividers |
| Destructive | `hsl(var(--destructive))` ≈ `#EF4444` | Delete material action only |

Accent `#F97316` reserved for:
- Active tab indicator (underline / text)
- "Thêm tài liệu" upload button (admin)
- "Đánh dấu đã xem" CTA button (existing LessonProgressButton)
- Category badge border (active filter)

Student card pattern: `.bm-clay-card-student` — white bg, `border border-orange-200/25`, `rounded-2xl`, subtle orange shadow.

## Study Materials Item

Each material row in Tab 1:

```
┌─────────────────────────────────────────────────┐
│ [📄] Đề thi giữa kỳ 2024.pdf   [Giữa kỳ] [↓]  │
└─────────────────────────────────────────────────┘
```

- Container: `flex items-center gap-3 px-4 py-3 rounded-xl border border-border/50 bg-white hover:bg-primary/5 transition-colors`
- File icon: lucide `FileText` / `Image` / `File` — `h-4 w-4 text-muted-foreground`
- Name: `text-sm text-foreground/80 flex-1 truncate`
- Category badge: `text-[10px] font-semibold px-2 py-0.5 rounded-full bg-primary/10 text-primary`
- Download button: lucide `Download`, `h-8 w-8`, icon-only, `min-h-[44px]` equivalent via padding
- Admin delete button (only `isAdmin`): lucide `Trash2`, `h-8 w-8 text-destructive/60 hover:text-destructive`

## Admin Upload Form (Tab 1, isAdmin only)

Inline above materials list:

```
┌─ Thêm tài liệu ──────────────────────────────────┐
│ [Chọn file...]   [Chọn loại ▾]  [Lớp ▾]  [Thêm] │
└──────────────────────────────────────────────────┘
```

- Trigger: `Button variant="outline"` with `Plus` icon — "Thêm tài liệu", `min-h-[44px]`
- Inline form appears below trigger (not dialog/modal)
- Category Select options: giữa kỳ / cuối kỳ / vào 10 / HSG / chuyên toán
- Grade Select options: Lớp 7 / Lớp 8 / Lớp 9
- Upload button: `Button variant="default"` (orange), "Tải lên", `min-h-[44px]`
- Loading state: `Loader2` spin, "Đang tải..."
- Cancel: `Button variant="ghost"`, "Hủy"

## Layout Constraints

**Critical (from project memory — 6-time scrollbar bug):**
- `LessonContent` tab area must NOT add `border-t` or `padding` to `<main>` wrapper
- Tab bar: `sticky top-0 bg-white z-10` is optional but must not create overflow
- Tab content panels: `overflow-y-auto` only if content can exceed viewport (avoid on panels that contain `SubmissionArea` which has internal scroll)
- `h-[calc(100vh-80px)]` layout inherited from `CourseDetailPage` — tab content must use `flex-1 min-h-0` inside the enrolled layout
