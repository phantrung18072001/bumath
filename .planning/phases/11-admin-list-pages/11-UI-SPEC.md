# Phase 11 — UI Design Contract: Admin List Pages

> Visual and interaction contract for `/quan-tri/nguoi-dung` (Users list) and
> `/quan-tri/khoa-hoc` (Courses list).
> Generated by `gsd-ui-researcher`. Design system established by Phase 10.
>
> **Scope:** Add pagination (client-side), search input, and role/grade filter controls
> to existing UsersPage.tsx and CoursesPage.tsx. Existing table markup and Loader2 spinners
> are replaced by Skeleton rows. All existing mutations (delete, publish) and dialogs
> (CourseFormDialog, UserEnrollmentDialog, AlertDialog) are preserved verbatim.

## Toolbar Layout

Both pages share the same toolbar structure, placed between the `h1` heading and the table.

```
<div className="flex flex-col sm:flex-row gap-2 mb-6">
  │
  ├── <Input>  ← search field, flex-1
  │     placeholder: see Copywriting Contract below
  │     leftIcon: <Search className="h-4 w-4 text-muted-foreground" />
  │     (wrap in relative div to position icon absolutely at left)
  │
  ├── <Select>  ← role filter (UsersPage) or grade filter (CoursesPage)
  │     width: w-[160px]
  │     options: see Copywriting Contract below
  │
  └── <span>  ← total count, only visible when not loading
        className="text-sm text-muted-foreground self-center whitespace-nowrap"
        copy: see Copywriting Contract below
```

**Mobile (< 640px):** Toolbar stacks vertically (`flex-col`). Search is full-width.
Select is full-width. Count appears below Select.

**Desktop (>= 640px):** Toolbar is horizontal row (`flex-row`). Search takes remaining
space. Select is fixed 160px. Count is right-aligned via `ml-auto` or natural flex end.

## Pagination Contract

| Property           | Value                                                               |
|--------------------|---------------------------------------------------------------------|
| Page size — Users  | 25 rows per page                                                    |
| Page size — Courses| 20 rows per page                                                    |

| Component          | shadcn `Pagination` (`src/components/ui/pagination.tsx`)           |
| Max visible pages  | Show up to 5 page numbers; ellipsis (`...`) for overflow            |
| Visibility         | Render pagination only when `totalPages > 1`                        |
| Active page style  | Uses shadcn `PaginationLink isActive` — inherits `--primary` bg     |

## Filter/Search Contract

### UsersPage Filters

| Control       | Type   | Options                                                             |
|---------------|--------|---------------------------------------------------------------------|
| Search        | Input  | Filter by `full_name` OR `phone` (case-insensitive substring match)|
| Role filter   | Select | "Tất cả vai trò" (sentinel `all`), "Học sinh", "Giảng viên", "Admin" |

Filter logic: `role === 'all' || user.role === role` AND `name/phone includes search`.
Both filters are ANDed together. Filtering and search operate on the full fetched array
before pagination slicing.

### CoursesPage Filters

| Control       | Type   | Options                                                             |
|---------------|--------|---------------------------------------------------------------------|
| Search        | Input  | Filter by `title` (case-insensitive substring match)               |
| Grade filter  | Select | "Tất cả lớp" (sentinel `all`), "Lớp 7", "Lớp 8", "Lớp 9", "Ôn chuyên" |

Filter logic: `grade === 'all' || course.target_grade === grade` AND `title includes search`.

## Skeleton Loading Contract

Replace the `Loader2` spinner block in both pages with skeleton rows.

```jsx
{/* Skeleton loading — 5 rows */}
<div className="space-y-2">
  {Array.from({ length: 5 }).map((_, i) => (
    <Skeleton key={i} className="h-10 w-full rounded-md" />
  ))}
</div>
```

- Import: `import { Skeleton } from '@/components/ui/skeleton'`
- Count: 5 rows for both pages (approximates a page of data while loading)
- Dimensions: `h-10` (40px height), `w-full`, `rounded-md`
- No column-level skeleton breakdown required (DS-02 only requires skeleton replaces spinner)
