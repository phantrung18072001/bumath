This is the only file in Phase 9 that requires new logic, not just string replacement.

**Step 1 — Add bidirectional mapping constants** near the top of the component (after imports, before the component function or inside it):

```ts
const LOI_MAP: Record<string, Course['target_grade']> = {
  '7': 'grade_7',
  '8': 'grade_8',
  '9': 'grade_9',
  'nang-cao': 'advanced',
}

const LOI_REVERSE: Record<Course['target_grade'], string> = {
  'grade_7': '7',
  'grade_8': '8',
  'grade_9': '9',
  'advanced': 'nang-cao',
}
```

**Step 2 — Update the query param READ** (line ~28):
```ts
// Before
const activeGrade = (searchParams.get('grade') ?? 'all')

// After
const lop = searchParams.get('lop') ?? 'all'
const activeGrade = lop === 'all' ? 'all' : (LOI_MAP[lop] ?? 'all')
```

**Step 3 — Update the `setGrade` function** (line ~55-61) to write `?lop=` Vietnamese values:
```ts
// Before
function setGrade(grade: Course['target_grade'] | 'all') {
  if (grade === 'all') {
    setSearchParams({})
  } else {
    setSearchParams({ grade })
  }
}

// After
function setGrade(grade: Course['target_grade'] | 'all') {
  if (grade === 'all') {
    setSearchParams({})
  } else {
    setSearchParams({ lop: LOI_REVERSE[grade] })
  }
}
```
