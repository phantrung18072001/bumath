## Typography

Taken from existing Login.tsx and AdminLayout.tsx — no new type roles needed.

**Declared scale: 2 weights — `font-medium` (500) for Body/Label, `font-semibold` (600) for Heading/Display.**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (text-base) | 500 (font-medium) | 1.5 | Form labels, nav link descriptions |

Source: measured from `Login.tsx` (h1: text-xl/font-semibold, labels: text-base/font-normal), `AdminLayout.tsx` (nav: text-sm/font-medium).

## Interaction Contracts

### ProtectedRoute: `allowedRoles` prop

| Scenario | Behavior |
|----------|----------|
| `allowedRoles` provided, user role is in the list | Render children |
| `allowedRoles` provided, `teacher` hits an admin-only route | Redirect to `/admin/submissions` |
| `allowedRoles` provided, `student` hits any admin route | Redirect to `/courses` |
| `requiredRole` provided (existing behavior) | Unchanged — redirect to `/` |
| `loading` is true | Show centered `Loader2 h-6 w-6 animate-spin text-primary` (no change) |
| No user | Redirect to `/login` (no change) |

Source: CONTEXT.md D-05, D-06.

### AdminLayout: nav item visibility

| Role | Visible nav items |
|------|------------------|
| `admin` | Quản lý tài khoản, Quản lý khóa học, Chấm bài (all three) |
| `teacher` | Chấm bài only |

Sidebar header label stays `Quản lý` for both roles (CONTEXT.md D-04). No role badge or label change in the sidebar.

Active state: `bg-primary text-primary-foreground`. Inactive: `text-muted-foreground hover:bg-muted hover:text-foreground`. These classes are unchanged.

### Login: post-login redirect

| Role | Redirect destination |
|------|---------------------|
| `admin` | `/admin/users` (unchanged) |
| `teacher` | `/admin/submissions` (new — was `/` placeholder) |
| `student` | `/courses` (unchanged) |
| `pending` / no role | Existing pending-page logic (unchanged) |

Source: CONTEXT.md D-07. The redirect fires in the `useEffect` watching `[user, loading, profile]`.
