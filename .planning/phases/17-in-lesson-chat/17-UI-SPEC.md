## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `hsl(var(--background))` | Chat panel background, message list area |
| Secondary (30%) | `hsl(var(--muted))` (#F2EDE8 approx) | Student message bubble background, reply indent border |
| Accent (10%) | `#F97316` (`--bm-primary`) | Send button background, unread badge background, active tab underline |
| Destructive | `hsl(var(--destructive))` (#E53E3E approx) | Delete message icon/button (teacher/admin only) |

Accent reserved for:
- Send button fill (`bg-[#F97316]`) — **primary focal point**: the orange Send button in the input row draws the eye as the sole high-contrast orange fill element on the screen. All other accent uses are decorative (borders, badges) at reduced opacity.
- Unread chat badge on Tab 3 trigger (e.g., "Thảo luận (2)")
- Active tab underline on Tab 3 when selected
- Teacher/admin reply bubble left border accent stripe

Student message bubble: `bg-muted` (light warm grey).
Teacher/admin message bubble: `bg-white` with `border border-[#F97316]/20` — visually distinct from student messages.

Source: `src/index.css` — `--bm-primary: #F97316`, `.bm-clay-card-student` border pattern `rgba(249,115,22,0.25)`, `CONTEXT.md` Phase 13 decisions

## Layout & Interaction Contract

### ChatPanel layout (inside `TabsContent value="thao-luan"`)

```
┌─────────────────────────────────────┐
│  Message list (ScrollArea)          │  flex-1, overflow-y scroll
│  ┌──────────────────────────────┐   │
│  │ ChatMessage (student)        │   │  bg-muted bubble, left-aligned
│  │   ↳ ChatReply (teacher)      │   │  indented 24px, orange left-border
│  │ ChatMessage (student)        │   │
│  └──────────────────────────────┘   │
├─────────────────────────────────────┤
│  ChatInput row                      │  shrink-0, sticky bottom
│  [ Textarea              ] [Send >] │
└─────────────────────────────────────┘
```

- ChatPanel height: fills `TabsContent` which fills `flex-1 min-h-0` of the lesson content area
- Message list auto-scrolls to bottom on new message arrival
- Scroll position is preserved when switching tabs (channel stays open only when tab is active per D-06)

### Message bubble anatomy

Student message:
- Sender name (weight 600, 12px) + timestamp (12px muted) on same line
- Message text (14px, 1.5 line-height) below
- No avatar; role label not shown for students

Teacher/admin message (reply or root):
- Sender name + `• Giảng viên` or `• Quản trị` suffix in muted text
- Left border: `border-l-2 border-[#F97316]` to visually differentiate
- Delete button (ghost, `Trash2` 16px) visible on hover — `opacity-0 group-hover:opacity-100 transition-opacity duration-150`

Reply indent:
- `ml-6` (24px) left margin
- `border-l-2 border-[#F97316]/30` visual indent marker
- Capped at 1 level — replies to replies display at same indent as direct replies (D-04, CONTEXT.md)

### Chat tab trigger with unread badge

```tsx
<TabsTrigger value="thao-luan">
  Thảo luận
  {unreadCount > 0 && (
    <Badge className="ml-1.5 bg-[#F97316] text-white text-[10px] px-1.5 min-w-[18px] h-[18px]">
      {unreadCount > 9 ? '9+' : unreadCount}
    </Badge>
  )}
</TabsTrigger>
```

Badge uses exact same styling as `BellNotification.tsx` existing red badge — only color changes to `#F97316`.

Note: Tab 3 is visible to both students and teachers/admins. The `!isAdmin` guard on the existing placeholder is removed when ChatPanel ships.

### Chat input behavior

- `Textarea` component, min 44px height, grows up to 120px (4 lines)
- Enter key sends message; Shift+Enter inserts newline
- Send button: `bg-[#F97316] hover:bg-[#ea6c0c] text-white` with `SendHorizontal` icon 16px
- Send button disabled + `opacity-60` when input is empty or whitespace-only
- After send: input cleared, focus returned to textarea, list scrolls to bottom

### Realtime channel lifecycle

- Channel opens when Tab 3 becomes active (`onValueChange === "thao-luan"`)
- Channel closes (`supabase.removeChannel`) on:
  - Tab change away from "thao-luan"
  - `lessonId` change
  - Component unmount
- Messages deduplicated by UUID `id` field to handle React StrictMode double-mount (D-07)

### Read tracking (teacher side)

- Opening Tab 3 upserts `lesson_chat_reads(user_id, lesson_id, read_at)` — no UI element, fires automatically
- Triggers `queryClient.invalidateQueries(['teacher-chat-unread'])` to clear bell badge count

## States Matrix

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | Initial fetch in progress | 3 `Skeleton` rows (48px height each, rounded-lg, `bg-muted`) |
| Empty | No messages yet | Centered `MessageCircle` icon (40px, muted/30) + heading + body copy |
| Has messages | Messages loaded | Scrollable `ChatMessage` list |
| Sending | Send in flight | Send button shows `Loader2` spinner 16px, `animate-spin`; input `pointer-events-none` |
| Send error | Supabase error | Toast (Sonner) — error variant |
| Delete confirm | Teacher clicks Trash2 | Inline confirmation row replaces delete icon: "Xoá tin nhắn này?" + "Xoá" (destructive) + "Giữ lại" buttons — NO modal dialog |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (student) | "Gửi câu hỏi" (send button label, visible as aria-label; icon-only on narrow) |
| Primary CTA (reply) | "Trả lời" — noun is implied by inline reply context: the button appears directly below the parent message, making the object of the action unambiguous. Alternative "Trả lời học sinh" is acceptable if wider touch target is needed. |
| Empty state heading | "Chưa có câu hỏi nào" |
| Empty state body | "Hãy đặt câu hỏi cho giảng viên về bài học này." |
| Input placeholder (student) | "Đặt câu hỏi về bài học này…" |
| Input placeholder (teacher/admin) | "Trả lời câu hỏi của học sinh…" |
| Error state (send fail) | "Không gửi được tin nhắn. Kiểm tra kết nối và thử lại." |
| Error state (load fail) | "Không tải được tin nhắn. Thử lại sau." |
| Delete inline confirm | "Xoá tin nhắn này?" → "Xoá" (destructive red) + "Giữ lại" |
| Tab trigger | "Thảo luận" (existing — no change) |
| Tab trigger with unread | "Thảo luận (N)" via Badge component overlay — not changing tab text |
| Teacher badge in message | "• Giảng viên" suffix after sender name |
| Admin badge in message | "• Quản trị" suffix after sender name |
| Loading skeleton aria-label | "Đang tải tin nhắn…" |

Destructive actions in this phase:
- Delete message (teacher/admin only): inline confirmation, no modal — pattern chosen for speed over safety since message text is visible and delete is immediate
- No student-facing destructive actions (students cannot delete per D-15)

## Accessibility

- Send button: `aria-label="Gửi câu hỏi"` (student) / `aria-label="Gửi trả lời"` (teacher)
- Delete button: `aria-label="Xoá tin nhắn"` + tooltip on hover
- Message list region: `role="log"` + `aria-live="polite"` for Realtime new messages
- Unread badge on tab: `aria-label="Thảo luận, N tin nhắn chưa đọc"` on `TabsTrigger`
- Textarea: `aria-label="Nội dung câu hỏi"` (student) / `aria-label="Nội dung trả lời"` (teacher)
- Contrast: `#F97316` on white = 2.98:1 — use only for decorative borders/badges, never for body text. All message text on `bg-muted` or `bg-white` passes 4.5:1.
- Focus ring: `ring-[#F97316]` on input focus — inherits `--ring` CSS variable

| Interaction | Duration | Easing | Notes |

| Tab switch | 0ms | — | No animation — existing tab pattern has none |
