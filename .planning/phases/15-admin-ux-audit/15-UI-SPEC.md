## Layout Contract

### AdminCourseDetailPage (`/quan-tri/khoa-hoc/:courseSlug`)

- **Page background:** `bg-[#F0FDFA]` (mint) — mirrors StudentCourseDetailPage
- **2-column layout:** `grid grid-cols-[320px_1fr]` on `lg:` breakpoint; single column stacked on mobile (`< 1024px`)
- **Left sidebar width:** 320px fixed; `overflow-y-auto [scrollbar-width:none]`; sidebar background `bg-white` with `border-r border-[#F97316]/20`
- **Right content area:** fills remaining width; `min-h-[calc(100vh-80px)]`; `overflow-y-auto`; background `bg-[#F0FDFA]`
- **Mobile:** sidebar hidden by default; accessible via Sheet drawer (matches student CourseDetailPage pattern — source: CONTEXT.md D-02, `CourseDetailPage.tsx`)
- **Primary focal point:** the video embed in the right content area, which occupies the largest visible real estate above the fold on desktop (16:9 aspect ratio, full column width). All other content area elements (title, description, assignments) are subordinate to the video block.

### Sidebar Structure (left column)

```
[Breadcrumb] — fixed at top, not scrollable
[Course title + grade badge] — sticky header
[Progress bar] — only if relevant context warrants; omit for admin view
[Chapter accordion list] — scrollable
  [Chapter row] — drag handle | title | action buttons (edit, delete, add lesson)
    [Inline form: ChapterInlineForm] — expand below row
    [Lesson rows] — drag handle | title | action buttons (edit, delete)
      [Inline form: LessonInlineForm] — expand below lesson row
  [+ Thêm chuyên đề] — button at bottom of chapter list
```

### Content Area (right column)

```
[Lesson header] — title, chapter name, grade badge
[Video embed] — YouTube iframe 16:9 aspect ratio  ← primary focal point
[Description] — prose text block
[Assignments] — attachment list (read-only)
[Loading skeleton] — shown while lesson data fetches
[Error state] — shown if lesson not found
```

### Inline Form Animation (Claude's Discretion — resolved)

- Use CSS `max-height` transition: `max-height: 0` → `max-height: 600px` over 200ms `ease-out`
- Tailwind: `overflow-hidden transition-[max-height] duration-200 ease-out`
- Only 1 inline form open at a time: opening a new form closes any currently open form (controlled by a single `openFormId: string | null` state at page level)
- No Framer Motion for inline forms (avoid bundle cost for admin-only feature)

### Loading Skeleton (Claude's Discretion — resolved)

Content area right column shows skeleton while lesson fetch is in-flight:
- 1 skeleton block `h-6 w-3/4` for title
- 1 skeleton block `aspect-video w-full rounded-lg` for video area
- 3 skeleton blocks `h-4 w-full` for description lines

Use shadcn `Skeleton` component (already installed).

## Interaction Contract

### Inline Form Behavior

1. Only one inline form may be open at a time across the entire sidebar.
2. Opening any inline form closes any currently open form without prompting (no unsaved warning in this phase).
3. "Thêm chuyên đề" button: expands `ChapterInlineForm` at the bottom of the sidebar, below all chapters.
4. "Sửa" on a chapter row: expands `ChapterInlineForm` directly below that chapter row.
5. "Thêm bài giảng" on a chapter row: expands `LessonInlineForm` below the last lesson in that chapter.
6. "Sửa" on a lesson row: expands `LessonInlineForm` directly below that lesson row.
7. Successful submit: close form, invalidate query, sidebar refreshes in place, no navigation.
8. Cancel (add mode): label "Hủy thêm" — close form, no state change.
9. Cancel (edit mode): label "Hủy chỉnh sửa" — close form, no state change.
10. Form open state: page-level `openFormId: string | null` (string encodes type+id, e.g. `"chapter-edit-{id}"` or `"chapter-add-new"`).

### DnD Reorder

- Drag handle (`GripVertical`) visible on every chapter and lesson row.
- Drag is pointer-sensor + keyboard-sensor (accessibility).
- On drag end: optimistic reorder in local state + API call `reorderChapters` / `reorderLessons`.
- Drag disabled when an inline form is open (set `disabled` on `DndContext`).

### Default Lesson Selection

- On page load: auto-select the first lesson of the first chapter.
- If no lessons exist: content area shows empty state for the course (not a lesson-level empty state).

### Lesson Content (read-only)

- Lesson detail in right column is always read-only display: title, video embed, description, assignments list.
- "Sửa" button for the active lesson is rendered in the content area header → clicking it opens the inline form in the sidebar for that lesson.

### Destructive Actions

All destructive actions use `AlertDialog` with:
- Title + body copy as specified in Copywriting Contract above
- Two buttons: cancel ("Giữ lại", `outline` variant) + confirm ("Xóa ...", `destructive` variant)
- No auto-close on background click for destructive dialogs

### Audit (AUDIT-01)

Audit is a code-only sweep — no new UI components or pages. Fixes are:
- Wire up missing `onClick` handlers on `<Button>` elements
- Fix `<Link to="...">` pointing to non-existent routes
- Fix `<a href="...">` with missing `href`
- No new UI patterns introduced during audit

## Accessibility

- All icon-only buttons (Sửa, Xóa, GripVertical): `aria-label` matching tooltip text
- Inline forms: `aria-expanded` on trigger button; form container `role="region"` with `aria-label="Form chỉnh sửa"`
- Sidebar lesson rows: `role="button"`, `aria-current="true"` when active
- Delete AlertDialog: focus trap inside dialog; "Giữ lại" button receives initial focus
- Progress bar in sidebar (if included): `aria-label` with percentage
- Keyboard navigation: Tab through sidebar rows; Enter/Space to expand inline form
