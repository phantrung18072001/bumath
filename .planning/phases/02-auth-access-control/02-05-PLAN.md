<objective>
Make Header.tsx auth-aware so logged-in users can sign out from any page that includes the Header.

Purpose: signOut is currently only accessible from Pending.tsx. Once a user is approved and lands on the Index page (which renders Header), there is no way to sign out. AUTH-03 requires "any logged-in user can log out from any page." The Header appears on Index and will appear on future content pages, making it the correct place for a universal logout.

Output: Header.tsx conditionally renders user info + "Dang xuat" button when authenticated, or the existing login/register buttons when not authenticated.
</objective>
