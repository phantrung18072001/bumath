## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, inline chip padding |
| sm | 8px | Stacked form field gaps, badge inner padding |
| md | 16px | Default element spacing, card inner padding sides |
| lg | 24px | Card padding (top/bottom), section vertical rhythm |
| xl | 32px | Between major card sections |
| 2xl | 48px | Page-level vertical centering offset |
| 3xl | 64px | Full-page centered auth layout top/bottom margin |

Exceptions:
- Minimum tap target: 48x48px (UX-02). All buttons and interactive rows in the admin table must meet this minimum. shadcn `Button size="default"` renders at h-10 (40px) — use `size="lg"` (h-11, 44px) for primary form CTAs, or apply `min-h-[48px]` explicitly for mobile touch targets.

## Typography

All text is in Vietnamese (UX-03). Font: "Be Vietnam Pro".

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 (regular) | 1.5 | Form helper text, table cell content, card body copy, form field labels, table column headers, badge text |
| Heading | 20px | 600 (semibold) | 1.3 | Page title (e.g. "Đăng nhập", "Đăng ký"), card section title |
| Label | 14px | 400 (regular) | 1.4 | Secondary labels, status text, helper text beneath form fields |
| Display | 28px | 600 (semibold) | 1.2 | Pending/rejected screen main message only |

Constraints:
- Maximum 4 type sizes declared above — do not introduce additional sizes in this phase.
- Weights used: 400 (regular) and 600 (semibold) only. Do not use 500, 700, 800, or 900 in auth screens (800/900 reserved for landing hero; 500/700 not used in this phase).
- Body line-height 1.5 applies to all paragraph and helper text.
- Heading line-height 1.3 applies to all page-level and card-level titles.

Destructive (`--destructive`, red) reserved for:

Status badge colors (using shadcn `Badge` variants):
- "Chờ duyệt" (pending) → `variant="secondary"` (blue, hsl(200 80% 50%))
- "Đã duyệt" (approved) → `variant="default"` with `bg-green-600` override
- "Từ chối" (rejected) → `variant="destructive"`

## Screen Inventory

This phase introduces the following new screens and components:

### `/login` — Login Page
- Centered card layout, max-width 400px, vertically centered on page
- Card contains: logo/brand mark (text only, no image), heading "Đăng nhập", form, link to `/register`
- Form fields: Số điện thoại (tel input), Mật khẩu (password input with show/hide toggle)
- Primary CTA button: full-width, `size="lg"`, primary color
- No header nav on this page — standalone auth layout (no landing Header)

### `/register` — Registration Page
- Centered card layout, max-width 480px (wider than login to accommodate more fields)
- Card contains: heading "Tạo tài khoản", form, link to `/login`
- Form fields (in order): Số điện thoại, Tên học sinh, Năm sinh, Địa chỉ, Mật khẩu, Xác nhận mật khẩu
- Primary CTA button: full-width, `size="lg"`, primary color
- No header nav — standalone auth layout

### `/pending` — Pending Approval Screen
- Centered card layout, max-width 420px
- Displays: icon (Clock or HourglassIcon from Lucide), display-size heading, body copy, processing time note, Zalo contact info, Đăng xuất button
- Background: `--background` (warm near-white)

### `/admin/users` — Admin User Management
- Full-width page layout with page heading "Quản lý tài khoản"
- Tabs component: "Tất cả" | "Chờ duyệt" | "Đã duyệt" | "Từ chối"
- Table with columns: Tên học sinh, Số điện thoại, Năm sinh, Địa chỉ, Trạng thái, Hành động
- Action column: "Duyệt tài khoản" button (primary) + "Từ chối" button (destructive outline) — visible only on pending rows
- Status column: Badge component per status
- No sidebar in this phase — full-width single-column layout

### `ProtectedRoute` component (non-visual)
- Wraps all routes requiring authentication
- Loading state during session check: full-page centered spinner (Lucide `Loader2` with `animate-spin`, 24px, primary color) — no skeleton, instant redirect if session is confirmed. Spinner must include `aria-label="Đang tải..."` on the wrapper element (or an `sr-only` span with text "Đang tải...") for screen reader accessibility.

## Interaction States

### Form Inputs
- Default: border `--border` (hsl(30 15% 88%))
- Focus: ring `--ring` (primary orange), 2px offset
- Error: border `--destructive`, helper text in `--destructive` color beneath field, 14px/400
- Disabled: opacity-50, cursor-not-allowed

### Buttons
- Primary (submit): `variant="default"` — orange background, white text. Loading state: `disabled` + Lucide `Loader2` icon spinning inline left of label text.
- Ghost (Đăng xuất on pending screen): `variant="ghost"` — no background, foreground text
- Destructive (Từ chối): `variant="destructive"` — red background, white text
- Outline (secondary admin action): `variant="outline"` — border only

### Phone Number Input
- Input type: `tel`
- Placeholder: "0912 345 678"
- Validation: Vietnamese local format (0xx xxxx xxxx). Form coerces to E.164 (+84...) before submitting to Supabase — this coercion is invisible to the user; the input accepts the local "0" prefix format.
- Error message on invalid format: "Số điện thoại không hợp lệ (VD: 0912345678)"

### Admin Table Row Actions
- "Duyệt tài khoản" and "Từ chối" buttons are inline in the Actions column
- After action completes: row status badge updates optimistically; row moves to correct tab on next tab switch (not instant row removal to avoid layout shift)
- Confirmation for Reject: inline — no modal dialog. Reject button becomes a two-step: first click changes button label to "Xác nhận từ chối?" with destructive styling, second click confirms. Auto-resets after 3 seconds if not confirmed.

## Layout Patterns

### Auth Pages (`/login`, `/register`)
- No landing page Header. Standalone layout.
- Full-viewport-height flex container: `min-h-screen flex items-center justify-center bg-background`
- Small BuMath-X text logo above the card (not the full header)
- Card: `rounded-2xl border bg-card p-6 shadow-lg` matching ConsultationForm pattern
- Mobile: card fills width with `mx-4` horizontal margin (no full-bleed)

### Pending / Rejected Screen (`/pending`)
- Same standalone layout as auth pages (no Header)
- Card max-width 420px, centered
- Icon centered above heading (Lucide `Clock` at 48px, `text-primary` color)
- Content stacked: icon → heading (Display) → body (Body) → contact (Body, muted) → Đăng xuất button (Ghost, full-width)

### Admin Page (`/admin/users`)
- Includes landing page Header (authenticated header state — shows user info + Đăng xuất)
- Page content: `container mx-auto px-4 py-8`
- Page heading (Heading size, 20px/600): "Quản lý tài khoản"
- Tabs below heading
- Table fills full width within container

## Responsive Behavior

- Breakpoint: mobile-first. All layouts work at 375px viewport width (UX-01).
- Auth card (`/login`, `/register`): full width minus `mx-4` (16px each side) on mobile; max-width 400px/480px on md+.
- Admin table: horizontal scroll on mobile (`overflow-x-auto` wrapper). Table columns do not collapse — scroll is the solution.
- All buttons: minimum 48px height on mobile (UX-02).
- Font sizes do not change between breakpoints in this phase — 16px body is readable on mobile without scaling.
