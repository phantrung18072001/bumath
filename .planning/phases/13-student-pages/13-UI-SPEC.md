## Claymorphism Card — Student Variant

> The existing `.bm-clay-card` (in `src/index.css`) uses `--bm-border: #F97316` (orange) — correct for auth pages on the dark chalkboard background.
> Student pages use a **teal** border variant on the mint `#F0FDFA` background. Add this new class alongside the existing one.

### New CSS class: `.bm-clay-card-student`

```css
/* Add to src/index.css after .bm-clay-card */
.bm-clay-card-student {
  background: #FFFFFF;
  border: 3px solid #0D9488;
  border-radius: 24px;
  box-shadow:
    0 8px 0 #0D9488,
    0 2px 0 rgba(255, 255, 255, 0.8) inset;
  transition: box-shadow 200ms ease, transform 200ms ease;
  cursor: pointer;
}

.bm-clay-card-student:hover {
  transform: translateY(-2px);
  box-shadow:
    0 10px 0 #0D9488,
    0 2px 0 rgba(255, 255, 255, 0.8) inset;
}

@media (prefers-reduced-motion: reduce) {
  .bm-clay-card-student {
    transition: none;
  }
  .bm-clay-card-student:hover {
    transform: none;
  }
}
```

### Tailwind Equivalent (for inline use where CSS class not applicable)

```
className="bg-white border-[3px] border-[#0D9488] rounded-3xl 
           shadow-[0_8px_0_#0D9488,0_2px_0_rgba(255,255,255,0.8)_inset]
           hover:-translate-y-0.5 hover:shadow-[0_10px_0_#0D9488,0_2px_0_rgba(255,255,255,0.8)_inset]
           transition-all duration-200 cursor-pointer
           motion-reduce:transition-none motion-reduce:hover:transform-none"
```

## Typography

| Role | Font Family | Size | Weight | Line Height | Tailwind Classes |
|------|-------------|------|--------|-------------|-----------------|
| Page heading | Baloo 2 | 24px | 700 | 1.2 | `text-2xl font-bold` |
| Card title | Baloo 2 | 20px | 600 | 1.3 | `text-xl font-semibold` |
| Body / description | Comic Neue | 16px | 400 | 1.5 | `text-base font-normal` |
| Label / caption | Comic Neue | 14px | 400 | 1.4 | `text-sm font-normal` |

**Usage rules:**
- `text-2xl font-bold` — Page `<h1>` headings only ("Khóa học của tôi", "Khám phá khóa học")
- `text-xl font-semibold` — Course card titles (`CardTitle`)
- `text-base font-normal` — Empty state body copy, description text, lesson names in sidebar
- `text-sm font-normal` — Progress labels, badge labels, muted captions, filter pill labels
- `text-[#134E4A]` (or `text-foreground`) — primary text color
- `text-muted-foreground` — secondary/caption text (#6B7280 equivalent via CSS var)

| Role | Value | CSS Variable / Tailwind | Usage |
|------|-------|------------------------|-------|
| Dominant (60%) — page bg | `#F0FDFA` | `bg-[#F0FDFA]` | Page backgrounds for ALL 3 student pages |

| Accent (10%) — CTA | `#F97316` | `bg-[#F97316]` / `.bm-btn-cta` | Primary CTA buttons ONLY ("Khám phá khóa học" empty state CTA, "Đăng nhập để học") |

**Accent reserved for:**
1. Primary CTA button: "Khám phá khóa học" (CoursesPage empty state)
2. "Đăng nhập để học" button (CataloguePage unauthenticated state)

**Color notes:**
- `bg-[#F0FDFA]` must be applied to the `<main>` or page wrapper `<div>` inside `StudentLayout`, not just the outer container
- `bg-background` currently resolves to `hsl(30 50% 98%)` (warm off-white) — override to `bg-[#F0FDFA]` on student pages explicitly
- Progress bar indicator fill: `style={{ '--tw-progress-fill': '#0D9488' }}` OR inject `bg-[#0D9488]` on the indicator element via className override (see Progress spec below)

### Progress Bar — Teal Fill Override

shadcn `<Progress>` uses a CSS variable `--tw-translate-x` trick internally. To apply teal fill, target the indicator element:

**Method: Add to `src/index.css`**
```css
/* BuMath teal progress override */
.bm-progress-teal [data-slot="progress-indicator"],
.bm-progress-teal > div {
  background-color: #0D9488 !important;
}
```

**Usage:**
```tsx
<Progress
  value={progress}
  className="h-3 bg-[#CCFBF1] bm-progress-teal"
  aria-label={`Tiến độ hoàn thành: ${progress}%`}
/>
```

Track (background): `bg-[#CCFBF1]` (teal-100 — tinted light teal)
Indicator (fill): `#0D9488` via `.bm-progress-teal` class
Height: `h-3` (12px) in CoursesPage cards, `h-2` (8px) in LessonSidebar header
