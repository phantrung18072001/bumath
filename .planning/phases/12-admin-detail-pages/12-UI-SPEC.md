# Phase 12 — UI Design Contract

> Visual and interaction contract for Admin Detail Pages. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui |
| Preset | style=default, baseColor=slate, cssVariables=true |
| Component library | Radix UI primitives via shadcn |
| Icon library | Lucide React |
| Font | Be Vietnam Pro (400, 500, 600, 700) — loaded in index.css |

**Admin theme rule (from CONTEXT.md D-11):** Admin pages use clean shadcn/Tailwind tokens only. No Claymorphism (`bm-clay-card`, `bm-float-symbol`, `--bm-*` variables), no chunky borders, no orange shadows. These are reserved for landing + auth pages.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Inline filter gaps, button icon spacing |
| md | 16px | Table cell padding, form field gap, card body padding |
| lg | 24px | Section padding, filter toolbar vertical padding |
| xl | 32px | Page header bottom margin |
| 2xl | 48px | n/a in admin pages |
| 3xl | 64px | n/a in admin pages |

Exceptions:
- Row action buttons: `min-h-[48px]` — mandatory touch target (from CONTEXT.md D-13)
- Mobile sticky bottom bar (GradingPage): `p-4` (16px) with `fixed bottom-0 left-0 right-0`
- Drag handle column width: 40px (accommodates 24px GripVertical icon + 8px each side)

---

## Typography

Font: Be Vietnam Pro across all admin pages.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / table cell | 14px | 400 | 1.5 |
| Label / filter text | 14px | 500 | 1.5 |
| Heading / page title | 20px | 600 | 1.2 |
| Score display (badge) | 13px | 600 | 1 |

Size set rationale: admin UI is data-dense; 14px body keeps rows compact while 20px titles provide hierarchy. Only 3 sizes used (13, 14, 20) to minimize visual noise. Only 2 weights (400, 600) — 500 is used for labels but treated as the "medium label" variant of the regular tier.

## Color

All values reference existing CSS variables from `src/index.css`. Admin pages use shadcn semantic tokens — no `--bm-*` custom vars.

| Role | CSS Variable | Resolved (light) | Usage |
|------|-------------|-----------------|-------|
| Dominant (60%) | `hsl(var(--background))` | off-white warm `#FAF9F7` approx | Page background |

Accent reserved for: "Lưu điểm" save button, "Thêm chương" / "Thêm bài học" add buttons, confirm action inside GradingPage sticky bar. Never used for filter controls, icons, or table headers.

## Interaction Contracts

### SubmissionsPage — Filter Toolbar

- Status filter: first in filter bar, `<Select>` with sentinel value `'all'` for "Tất cả" default. Options: `'all'` / `'ungraded'` / `'graded'`.
- Filter change resets `currentPage` to 1 (from CONTEXT.md D-03).
- Score badge in graded rows: `<Badge className="bg-teal-100 text-teal-800 border-0">` with numeric score value.
- Empty table (no results): show centered empty state row spanning all columns — see Copywriting Contract below.
- Loading: 5x skeleton rows `<Skeleton className="h-10 w-full rounded-md" />` in `<div className="space-y-2">` wrapped in `<div aria-busy="true" aria-label="Đang tải...">` (from CONTEXT.md D-10).

### GradingPage — Mobile Sticky Bar

- Breakpoint: hidden on `lg:` and above, visible on `lg:hidden`.
- Markup: `<div className="fixed bottom-0 left-0 right-0 bg-background border-t p-4 lg:hidden">`.
- Contains: score `<Input>` + "Lưu điểm" `<Button>` + double-confirm flow (pendingConfirm state, same logic as desktop sidebar).
- Desktop layout (side-by-side sticky sidebar with score + comment): unchanged.
- Scrollable image area: `overflow-y-auto` with enough bottom padding (`pb-24`) to prevent sticky bar overlap on mobile.

### ChaptersPage + LessonsPage — Drag-and-Drop Reordering

- Replace `ChevronUp` / `ChevronDown` buttons with dnd-kit `DndContext` + `SortableContext` (array strategy, `closestCenter` collision detection — from CONTEXT.md Claude's Discretion).
- Drag handle: first column in table, 40px wide. Uses `<GripVertical className="h-4 w-4 text-muted-foreground" />`. `cursor-grab` on idle, `cursor-grabbing` on active drag.
- Optimistic UI update: reorder rows visually on drop before Supabase confirms (from CONTEXT.md Claude's Discretion). On mutation error, invalidate query to restore server state.
- Existing edit/delete buttons: preserved in action column, position unchanged.
- Loading: 5x skeleton rows (same pattern as SubmissionsPage D-10).
- Row during drag: `opacity-50` on dragged row, destination placeholder rendered by dnd-kit.

### Server-Side Pagination (UsersPage, CoursesPage, SubmissionsPage)

- Total count displayed: "X người dùng" / "X khóa học" / "X bài nộp" as small muted text right of page heading.
- Pagination component: `<Pagination>` from shadcn, `justify-between` layout with count on left and page controls on right (Phase 11 pattern).
- Page size labels: UsersPage=25/trang, CoursesPage=20/trang, SubmissionsPage=20/trang.
