## Component Specifications

### 1. Public Page `/tai-lieu`

**Layout:** `Header` (landing) + main content + `Footer` (landing) — same as `GioiThieu.tsx`.

**Hero section:**
```
[Header]
────────────────────────────────────────────
  Tài liệu học tập                 [Display 28px bold]
  Tải miễn phí tài liệu PDF theo từng khối lớp  [Body 14px muted]
────────────────────────────────────────────
```
Background: white. No decorative floating symbols (keep page clean/functional).

**Grade filter bar:**
- Pattern: horizontal scrollable button group, same as `CataloguePage.tsx`
- Options in order: `Tất cả` | `Lớp 7` | `Lớp 8` | `Lớp 9` | `Ôn thi chuyên`
- Active pill: `bg-primary text-white font-bold rounded-full px-4 py-2`
- Inactive pill: `bg-muted text-muted-foreground hover:bg-muted/80 rounded-full px-4 py-2`
- Container: `flex gap-2 flex-wrap` (wraps on mobile, does NOT scroll horizontally)
- State: `useState<'all' | 'grade_7' | 'grade_8' | 'grade_9' | 'advanced'>('all')`
- Default: "Tất cả" selected

**Card grid:**
- Layout: `grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-3`
- (3-col max — PDF documents are content-dense, 4-col too narrow for Vietnamese titles)

**PDF Card anatomy:**
```
┌─────────────────────────────────┐
│  [FileText 32px orange icon]    │  ← top-left or centered
│                                 │
│  Đề thi thử vào 10 toán...     │  ← title, 16px regular, 2-line clamp
│                                 │
│  [Lớp 9 badge]                  │  ← grade badge from GRADE_BADGE
│                                 │
│  [⬇ Tải xuống]                 │  ← orange button, full-width
└─────────────────────────────────┘
```
- Card class: `.bm-clay-card-student` (3px orange border, lift on hover, 24px radius)
- PDF icon: `<FileText className="h-8 w-8 text-primary" />` — centered in a `bg-primary/5 rounded-xl p-3` container
- Title: `line-clamp-2` (max 2 lines, ellipsis overflow)
- Grade badge: `<Badge className={GRADE_BADGE[grade].className}>` — reuse existing constant
- Download button: `<Button className="bm-btn-cta w-full gap-2">` with `<Download className="h-4 w-4" />`
- Download loading state: replace `<Download>` icon with `<Loader2 className="h-4 w-4 animate-spin" />`, button disabled

**Skeleton loading (isLoading):**
- Render 6 skeleton cards in same grid
- Each skeleton: `<Skeleton className="h-48 rounded-2xl" />` (matches card height)

### 2. Admin Page `/quan-tri/tai-lieu`

**Layout:** `AdminLayout` wrapping content. `<ProtectedRoute allowedRoles={['admin', 'teacher']}>`.

**Page title:** "Quản lý tài liệu" (h1, text-2xl font-bold)

**Upload form section** (inline, no dialog — D-09):
- Section header: "Tải lên tài liệu mới" (text-xl font-bold, with Upload icon)
- Form container: `bg-muted/50 rounded-xl p-6 border border-border` (secondary color bg)
- Fields (vertical stack, gap-4):
  1. **Tiêu đề** — `<Input placeholder="Nhập tiêu đề tài liệu..." />` with Label
  2. **Khối lớp** — `<Select>` dropdown (agent discretion: Select is more compact than radio for admin form)
     - Options: Lớp 7 / Lớp 8 / Lớp 9 / Ôn thi chuyên (maps to grade_7 / grade_8 / grade_9 / advanced)
  3. **File PDF** — `<Input type="file" accept=".pdf" />` with Label "Chọn file PDF"
     - File constraint: `.pdf` only, displayed below input as helper text
- Submit button: `<Button className="bm-btn-cta gap-2"><Upload className="h-4 w-4" />Tải lên</Button>`
- Submit loading: button disabled + `<Loader2 animate-spin>` + text "Đang tải lên..."
- Form validation: all 3 fields required before submit enabled

**Admin list section:**
- Section header: "Danh sách tài liệu" (text-xl font-bold, with FileText icon) + item count badge
- Layout: `<Table>` (shadcn Table) with columns: Tiêu đề | Khối lớp | Ngày tải | Hành động
- Grade column: render `<Badge>` from GRADE_BADGE constant
- Ngày tải: formatted as `dd/MM/yyyy`
- Hành động column: `<Button variant="destructive" size="sm" gap-2><Trash2 />Xóa</Button>`
- Delete flow: opens `<AlertDialog>` for confirmation before calling deleteStudyMaterial()
- Empty list: centered empty state (see copywriting below)

## Interaction Contracts

### Download Flow (Public Page)
1. User clicks "Tải xuống"
2. Button enters loading state (Loader2 spinner, disabled)
3. Call `getStudyMaterialSignedUrl(material.file_path)` → signed URL (1h TTL)
4. On success: `window.open(url, '_blank', 'noopener')` → PDF opens in new tab
5. Button returns to normal state
6. On error: `toast.error("Không thể tải tài liệu. Vui lòng thử lại.")` — button returns to normal

### Upload Flow (Admin Page)
1. Admin fills title + selects grade + selects PDF file
2. Clicks "Tải lên" → button enters loading state
3. Call `uploadStandaloneStudyMaterial(file, { title, grade })` (file path prefix: `standalone/`)
4. On success: `toast.success("Tải lên thành công!")` → form resets → TanStack Query invalidates `['standalone-materials']`
5. On error: `toast.error("Tải lên thất bại. Vui lòng thử lại.")` → form stays filled

### Delete Flow (Admin Page)
1. Admin clicks "Xóa" on a row
2. `<AlertDialog>` opens with confirmation copy (see Copywriting)
3. On confirm: call `deleteStudyMaterial(id, filePath)` → list refreshes
4. On success: `toast.success("Đã xóa tài liệu.")` → TanStack Query invalidates
5. On error: `toast.error("Xóa thất bại. Vui lòng thử lại.")`

### Grade Filter (Public Page)
- Client-side filter: `useState` controls active grade
- `activeGrade === 'all'` → show all materials
- Otherwise: filter `materials.filter(m => m.grade === activeGrade)`
- No API re-fetch on filter change (all data fetched once, filtered client-side)
- QueryKey: `['standalone-materials']` (fetch all, filter in component)
