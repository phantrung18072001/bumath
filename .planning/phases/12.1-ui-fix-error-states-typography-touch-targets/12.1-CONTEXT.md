<decisions>
## Implementation Decisions

### Error States (all 3 list pages)
- **D-01:** Add `isError` destructuring from `useQuery` on SubmissionsPage, ChaptersPage, and LessonsPage.
- **D-02:** Error UI pattern: render `<p className="text-destructive py-8 text-center">Không thể tải dữ liệu. Vui lòng thử lại.</p>` before the skeleton/empty-state branch. No retry button — plain message only.
- **D-03:** Order: `{isError ? <error> : isLoading ? <skeleton> : data.length === 0 ? <empty-state> : <table>}`

### Typography
- **D-04:** `text-base` → `text-sm` for all empty-state headlines. Affected: `CoursesPage.tsx:189,198`, `UsersPage.tsx:186,191` — 4 instances total.
- **D-05:** `font-medium` → `font-normal` for index-number cells and course-title cell. Affected: `ChaptersPage.tsx:89`, `LessonsPage.tsx:95`, `CoursesPage.tsx:221` — 3 instances total.
- **D-06:** `font-mono` on score badge (`SubmissionsPage.tsx:254`) — KEEP (accepted, visually reasonable for number alignment).

### Touch Targets (GradingPage)
- **D-07:** Fix `min-h-[40px]` → `min-h-[48px]` on "Thêm ảnh phản hồi" button at `GradingPage.tsx:276`.
- **D-08:** Add `overflow-y-auto` and `pb-24` to the mobile image area container in GradingPage (the section that wraps the submitted images on mobile, roughly `GradingPage.tsx:159-200`). This prevents the sticky bottom bar from overlapping content.

### Copywriting
- **D-09:** "chuyên đề" terminology throughout ChaptersPage — ACCEPTED as intentional product decision. No changes.
- **D-10:** SubmissionsPage title "Chấm bài" — ACCEPTED. No change.
- **D-11:** Fix ChaptersPage delete dialog title: `"Xóa chuyên đề"` → `"Xóa chuyên đề?"` (add `?` per spec pattern).

### Color
- **D-12:** Count badge in SubmissionsPage: change `bg-orange-100 text-orange-700` → `bg-muted text-muted-foreground`. This preserves the "orange = action" signal for CTAs while using the CSS variable system for informational badges.

### Accessibility
- **D-13:** Add `aria-label="Đang tải..."` to the GradingPage Loader2 container div (`GradingPage.tsx:119-125`).
- **D-14:** Add `prefers-reduced-motion` support for dnd-kit drag animations in ChaptersPage and LessonsPage. Approach: add a CSS rule `@media (prefers-reduced-motion: reduce) { [data-dnd-dragging] { transition: none; } }` or use dnd-kit's `modifiers` to disable the animation when reduced motion is preferred.

### Agent's Discretion
- Exact CSS selector/approach for `prefers-reduced-motion` with dnd-kit — use whichever approach integrates cleanly with existing SortableRow implementation (CSS media query preferred over JS modifier for simplicity)
- Whether to extract the error state JSX into a shared component or inline it per page — inline is fine given only 3 pages

</decisions>
