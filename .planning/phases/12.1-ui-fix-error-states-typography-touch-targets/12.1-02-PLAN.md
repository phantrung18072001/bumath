  <action>
Add this CSS rule at the end of `src/index.css` (after all existing rules):

```css
/* Accessibility: Disable dnd-kit drag animations for users who prefer reduced motion */
@media (prefers-reduced-motion: reduce) {
  [data-dnd-dragging],
  [data-dnd-sortable] {
    transition: none !important;
    transform: none !important;
  }
}
```

This targets dnd-kit's data attributes and disables CSS transitions/transforms when the OS prefers-reduced-motion setting is enabled.
  </action>
