## Spacing Scale

Standard 8-point scale from `design-system/bumath/MASTER.md`. No exceptions for this phase
except touch targets.

| Token | Value | Usage                                                    |
|-------|-------|----------------------------------------------------------|
| xs    | 4px   | Icon-to-label gaps, inline tight spacing                 |
| sm    | 8px   | Form field internal gaps, logo gap                       |
| md    | 16px  | Form field vertical spacing (`space-y-4`), card padding mobile |
| lg    | 24px  | Card padding mobile fallback, section spacing            |
| xl    | 32px  | Card padding desktop, logo-to-card gap (`mb-8`)          |
| 2xl   | 48px  | Page vertical breathing room (`py-12`)                   |
| 3xl   | 64px  | Not used in this phase                                   |

**Exceptions:**
- CTA buttons: `min-height: 48px` (touch target — existing pattern preserved)
- Logo image height: 44px (brand guideline, D-02/D-03)
- Math symbol touch target: none (pointer-events: none, decorative only)

## Typography

| Role             | Font       | Size  | Weight | Line Height | Usage                                  |
|------------------|------------|-------|--------|-------------|----------------------------------------|
| Logo text        | Baloo 2    | 30px  | 700    | 1.2         | "BuMath" brand name beside logo image  |
| Card heading h1  | Baloo 2    | 24px  | 700    | 1.2         | "Đăng nhập" / "Tạo tài khoản"         |
| Form label       | Comic Neue | 16px  | 400    | 1.5         | Field labels ("Số điện thoại", etc.)   |
| Helper / link    | Comic Neue | 14px  | 400    | 1.5         | Footer link copy, validation messages  |

**Implementation notes:**
- Apply `font-['Baloo_2']` (Tailwind arbitrary) or `style={{ fontFamily: "'Baloo 2', sans-serif" }}`
  to logo text and headings.
- Apply `font-['Comic_Neue']` or `fontFamily: "'Comic Neue', cursive"` to labels and helper text.
- Do NOT change the global `body` font-family (Be Vietnam Pro) — it affects other pages.
- Tailwind config: add custom fontFamily entries under `theme.extend.fontFamily`:
  ```ts
  fontFamily: {
    'baloo': ['"Baloo 2"', 'sans-serif'],
    'comic': ['"Comic Neue"', 'cursive'],
  }
  ```
  Then use `font-baloo` and `font-comic` as Tailwind classes.

## Accessibility Contract

| Requirement                  | Implementation                                                    |
|------------------------------|-------------------------------------------------------------------|
| Input labels                 | `<label htmlFor="...">` / shadcn `<FormLabel>` with correct `id` |
| Error association            | `<FormMessage>` renders `aria-describedby` (shadcn built-in)     |

| Password toggle              | `aria-label="Hiện mật khẩu"` / `"Ẩn mật khẩu"` (existing, preserved) |
| Math symbols                 | `aria-hidden="true"` on all 6 float spans                         |
| Logo image                   | `alt="BuMath logo"` on `<img>`                                   |
| Reduced motion               | `@media (prefers-reduced-motion: reduce)` disables float animation|
| Color contrast               | `#134E4A` on `#F0FDFA` → ≥ 7:1 ✓; `#0D9488` on white → ≥ 4.5:1 ✓ |
| Keyboard navigation          | Tab order: phone → password → submit → footer link (Login)       |

> **Note on CTA contrast:** `#F97316` white text ≈ 2.68:1 — below WCAG AA for normal text.
> Accepted tradeoff — BuMath design system locks this value. Button text is 16px bold;
> recommend `font-size: 18px` on CTA to shift to "large text" (3:1 threshold) if audited.
