<objective>
To build the Admin Chapters page at `/admin/courses/{courseId}` which lists all chapters for a specific course, allowing creation, editing, deletion, and reordering.
</objective>

<context>
- This relies on the table `chapters` and `courses`.
- URL structure connects back to `/admin/courses` using Breadcrumb component.
- The reorder mechanism doesn't use Drag and Drop, only [↑][↓] buttons swapping the `order_index`.
</context>

<tasks>
1. Setup Chapter API functions
   - Create `src/lib/api/chapters.ts` for fetch, insert, update, remove.
   - Include `reorderChapters` function that swaps `order_index` of two records.
2. Build Chapter List Page Framework
   - Create `src/pages/admin/ChaptersPage.tsx`.
   - Add `/admin/courses/:courseId` to `App.tsx` routes.
   - Add `Breadcrumb` navigating back to Courses.
   - Fetch the active course name (to display in breadcrumb).
3. Build Chapters Table
   - Add Table fetching `chapters` via TanStack query.
   - Build UI for reorder buttons [↑][↓]. Disable top arrow for 1st row, down for last row.
   - Add Edit and Delete icons.
4. Build Create/Edit Chapter Dialog
   - Create `ChapterFormDialog.tsx`.
   - Validate `title` using RHF/Zod.
   - Hook mutations for creation and editing, maintaining proper query invalidation so the list auto-updates.
5. Setup Reorder Handling
   - Wire `[↑][↓]` clicks to the `reorderChapters` API, invalidate queries to redraw the list.
</tasks>
