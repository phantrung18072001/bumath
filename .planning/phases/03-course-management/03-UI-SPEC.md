## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding, inline button icon margins |
| sm | 8px | Gap between action buttons in table rows (`gap-2`) |
| md | 16px | Container horizontal padding (`px-4`), form field vertical gaps |
| lg | 24px | Section top margin below page heading (`mb-6`) |
| xl | 32px | Container vertical padding (`py-8`) |
| 2xl | 48px | Minimum button touch target height (`min-h-[48px]`) |
| 3xl | 64px | Loader centering vertical padding (`py-16`) |

Exceptions:
- Touch targets: all interactive buttons use `min-h-[48px]` (48px — source: UX-02 requirement, UsersPage.tsx pattern)
- Icon size (inline): 16px / `h-4 w-4` for action icons within text
- Icon size (loading spinner): 32px / `h-8 w-8` for full-page loading state
- Reorder buttons [↑][↓]: `size="sm"` with `min-h-[48px]` override to meet touch target requirement

## Color

| Role | CSS Variable | HSL Value | Usage |
|------|-------------|-----------|-------|
| Dominant (60%) | `--background` | hsl(30 50% 98%) — warm white | Page background, all admin page surfaces |
| Secondary (30%) | `--card` + `--muted` | hsl(0 0% 100%) / hsl(30 20% 94%) | Cards listing courses/chapters/lessons; table row alternation via muted |
| Accent (10%) | `--primary` | hsl(24 95% 53%) — orange | Primary CTA buttons: "Tạo khóa học", "Tạo chuyên đề", "Lưu bài học", "Thêm enrollment" |
| Destructive | `--destructive` | hsl(0 84% 60%) — red | Delete course button, delete chapter button, delete lesson button, remove enrollment button — all in AlertDialog confirmation only |

Source: index.css `:root` CSS variables.

Accent reserved for:
1. "Tạo khóa học" button on `/admin/courses`
2. "Tạo chuyên đề" button on `/admin/courses/{courseId}`
3. "Thêm bài học" button on `/admin/courses/{courseId}/chapters/{chapterId}`
4. "Thêm khóa học" (enrollment add) button on user detail panel in `/admin/users`
5. Form submit buttons ("Lưu khóa học", "Lưu chuyên đề", "Lưu bài học", "Tạo khóa học", "Tạo chuyên đề") inside Dialog and lesson form
6. Do NOT use accent on reorder [↑][↓] buttons — use `variant="outline"` instead

Grade target badges use semantic colors (not accent):
- Lớp 7 — `bg-blue-100 text-blue-700`
- Lớp 8 — `bg-green-100 text-green-700`
- Lớp 9 — `bg-purple-100 text-purple-700`
- Ôn chuyên — `bg-orange-100 text-orange-700` (uses orange to match brand primary, not primary button color — text-only badge, no confusion with CTA)

Secondary semantic color: `--secondary` hsl(200 80% 50%) — blue. Not used in this phase (reserved for Phase 4 student-facing UI).

## Layout Contract

Primary focal point: `<h1>` page title + primary CTA button in header bar.

### Page Shell (all 3 admin pages)

```
<div class="container mx-auto px-4 py-8">
  <div class="flex items-center justify-between mb-6">
    <div class="flex items-center gap-3">
      [← Quay lại button — visible on level 2 and 3 only]
      <Breadcrumb /> [shadcn breadcrumb.tsx]
    </div>
    [Primary CTA button — right-aligned]
  </div>
  <h1 class="text-xl font-semibold leading-[1.3] mb-6">{Page title}</h1>
  {Content — Table or loading spinner}
</div>
```

### Breadcrumb Levels

| URL | Breadcrumb |
|-----|-----------|
| `/admin/courses` | Khóa học |
| `/admin/courses/{courseId}` | Khóa học > {Tên khóa học} |
| `/admin/courses/{courseId}/chapters/{chapterId}` | Khóa học > {Tên khóa học} > {Tên chuyên đề} |

### Content Tables

Follow UsersPage.tsx pattern exactly:
- Outer div: `overflow-x-auto`
- shadcn `Table` with `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell`
- Loading state: centered `Loader2` spinner with `h-8 w-8 animate-spin text-primary` inside `flex justify-center items-center py-16`
- Action buttons in last column with `flex gap-2 flex-wrap`

### Form Placement

| Form | Placement | Rationale |
|------|-----------|-----------|
| Create/Edit Course | Dialog (modal) | 3 fields — name, description, grade target. Compact enough for Dialog. |
| Create/Edit Chapter | Dialog (modal) | 2 fields — title, sort_order (auto). Compact. |
| Create/Edit Lesson | Full page or Dialog with scroll | 4+ fields — title, YouTube URL, description, sort_order, file upload. Use Dialog with scroll; if file upload is awkward, promote to dedicated page. Claude's discretion at implementation time. Prefer Dialog first. |

### Reorder Buttons [↑][↓]

- Use `Button variant="outline" size="sm"` with `min-h-[48px]` override
- `ArrowUp` and `ArrowDown` icons from Lucide React
- Disabled state: first item's [↑] disabled, last item's [↓] disabled
- Place in second-to-last column before action column

### File Upload (Lesson Attachment)

- Render as `<input type="file" accept=".pdf,image/*" />` styled via shadcn `Input`
- After selection: display file name and size below the input (e.g., "detoan.pdf — 245 KB")
- If existing file: show filename with `[Xóa file]` button (variant="outline", text-destructive)
- Accepted formats: PDF and images (per D-07, COURSE-04)

## Accessibility Contract

- All interactive elements: minimum 48x48px touch target (via `min-h-[48px]` on buttons, `min-h-[48px]` on Select trigger)
- Icon-only buttons ([↑][↓], edit, delete): include `aria-label` in Vietnamese (e.g., `aria-label="Di chuyển lên"`, `aria-label="Di chuyển xuống"`, `aria-label="Chỉnh sửa"`, `aria-label="Xóa"`)
- Form fields: all inputs connected to labels via `htmlFor`/`id` or wrapped in `FormItem` (which handles this via shadcn Form)
- AlertDialog: manages focus automatically via Radix — no additional work needed
- Loading spinners: include `aria-label="Đang tải..."` (matches UsersPage.tsx pattern)
