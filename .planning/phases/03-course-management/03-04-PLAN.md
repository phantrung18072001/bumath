<objective>
To implement the Admin Lessons page at `/admin/courses/{courseId}/chapters/{chapterId}` to handle complex lesson objects including YouTube URL extraction and File attachments. Support for COURSE-02 to COURSE-04.
</objective>

<context>
- Handles `lessons` table interactions.
- Integrates with Supabase Storage `assignments` bucket for PDF/Image uploads.
- Lesson schema requires extracting youtube `id` from arbitrary URLs.
</context>

<tasks>
1. Extract Utilities and APIs
   - Write regex utility `extractYouTubeID` in `src/lib/utils.ts` or `src/lib/youtube.ts`.
   - Create `src/lib/api/lessons.ts` for CRUD and `reorderLessons()`.
   - Add Supabase storage helper to `lessons.ts` for uploading file and deleting existing file.
2. Build Lessons Page Framework
   - Create `src/pages/admin/LessonsPage.tsx`.
   - Register `/admin/courses/:courseId/chapters/:chapterId` route in `App.tsx`.
   - Add 3-level breadcrumb.
3. Build Lessons List Table
   - Create list, including [↑][↓] reorder logic mirroring `ChaptersPage`.
   - Render an indicator cell if an attachment exists.
4. Integrate Complex Lesson Form Dialog
   - Create `LessonFormDialog.tsx` (Use Dialog with internal scroll per UI-SPEC).
   - Add text fields: title, youtube_url, description.
   - Add file upload logic: limit to `application/pdf` and `image/*`, < 10MB.
   - Show uploaded file name & size summary in form. Upload directly to bucket before inserting lesson record.
5. Handle File Cleanup
   - When a lesson is deleted, delete its assignment attachment from bucket as well.
</tasks>
