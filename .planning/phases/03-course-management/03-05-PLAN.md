<objective>
To implement Enrollment Management for Admins (assigning students to courses) within the existing `/admin/users` page setup. Fulfills COURSE-05 requirement.
</objective>

<context>
- Handled via `enrollments` table mapping `user_id` to `course_id`.
- Handled uniquely per student on `UsersPage.tsx` or a dialog accessed explicitly from that page.
- We cannot use Bulk Enrollment in v1 (D-08, Deferred ADMIN-V2-01).
</context>

<tasks>
1. Extract User Enrollments APIs
   - Create `src/lib/api/enrollments.ts`.
   - Implement `getUserEnrollments(userId)` (joining `courses` table for title/grade).
   - Implement `addEnrollment(userId, courseId)` and `removeEnrollment(enrollmentId)`.
2. Integrate into Users Page
   - Update `src/pages/admin/UsersPage.tsx`.
   - Add a row action column to "Assign Courses" or implement as an Expandable Row / dedicated Modal Dialog upon clicking on a student's `View` button.
   - Let's use a Dialog triggered by a "Quản lý khóa học" button next to "Duyệt/Từ chối" or inside a Row Actions dropdown.
3. Build Enrollments Management Dialog
   - Create `UserEnrollmentDialog.tsx`.
   - Display a list table of courses the user is currently enrolled in, and an action to `[Xóa]` the enrollment.
   - Display a dropdown `<Select>` containing all available courses the student is **not** currently enrolled in + an "Add" button to create an enrollment.
   - Badge colors for grades matching UI-SPEC colors must be present to distinguish course targets.
4. Verify Permissions Matrix
   - Ensure RLS rules configured in Plan 01 work adequately via the API calls and mutations.
</tasks>
