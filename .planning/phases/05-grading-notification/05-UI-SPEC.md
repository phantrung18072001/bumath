## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline gaps |
| sm | 8px | Compact element spacing, button icon margin |
| md | 16px | Default element spacing, dialog padding, table cell padding |
| lg | 24px | Section padding, dialog section breaks |
| xl | 32px | Layout gaps, page-level padding |
| 2xl | 48px | Major section breaks; also minimum touch target height (UX-02) |
| 3xl | 64px | Page-level vertical spacing |

Exceptions:
- All buttons and interactive controls must have `min-h-[48px]` to satisfy UX-02 (established in Phases 2–4)
- Dialog max image height: `max-h-[60vh]` for submission photo (D-07, CONTEXT.md) — viewport-relative, not token-based
- Bell badge absolute-positioned over icon: 16px wide × 16px tall red circle

Source: Established 8-point scale from Phase 2–4 patterns; UX-02 from REQUIREMENTS.md

## Interaction Contract

### Teacher Grading Queue (`/admin/submissions`)

**Page layout:**
- `container mx-auto px-4 py-8` — matches UsersPage pattern
- Page title: `<h1 className="text-xl font-semibold leading-[1.3] mb-6">Chấm bài</h1>`
- Count badge immediately after title: `<Badge>X bài chờ chấm</Badge>` — hidden when count = 0
- Table occupies full width, wrapped in `overflow-x-auto`

**Table columns:** Học sinh | Khóa học | Bài học | Ngày nộp | Hành động

**"Chấm bài" button in table row:**
- `<Button size="sm" className="min-h-[48px]">Chấm bài</Button>`
- Opens GradingDialog — row stays visible until save confirms

**Loading state:** Centered `<Loader2 className="h-8 w-8 animate-spin text-primary" />` with `py-16`

**Empty state:**
- `<p className="text-center text-muted-foreground py-8">Không có bài nào chờ chấm.</p>`

### GradingDialog

**Trigger:** "Chấm bài" row button → sets `gradingSubmission` state → Dialog `open={!!gradingSubmission}`

**Dialog structure (top to bottom):**
1. `DialogTitle`: "Chấm bài: [Tên học sinh] — [Tên khóa] — [Tên bài học]" — 16px/600
2. Submission photo: `<img className="w-full max-h-[60vh] overflow-y-auto object-contain rounded-md" />` inside scrollable div — loaded via signed URL
3. Score row: `<Input type="number" min={0} max={10} step={0.5} className="w-24" />` + `<span className="text-sm text-muted-foreground">/10</span>` — flex row with gap-2
4. Comment field: `<Textarea placeholder="Ví dụ: Làm đúng bước 1, cần kiểm tra lại dấu..." rows={3} />`  — optional
5. DialogFooter: `[Hủy]` (ghost/outline) | `[Lưu điểm]` (primary, min-h-[48px])

**Loading image state:** `<Skeleton className="w-full h-48 rounded-md" />`

**After save success:**
- Dialog closes (`setGradingSubmission(null)`)
- Row disappears (query invalidation)
- Toast: `toast.success('Đã lưu điểm cho [Tên học sinh]')`

**After save error:**
- Dialog stays open
- Toast: `toast.error('Lưu điểm thất bại. Vui lòng thử lại.')`

### Bell Notification (StudentLayout header)

**Placement:** Right side of header, between username and logout button

**Structure:**
```
<button className="relative min-h-[48px] min-w-[48px] flex items-center justify-center">
  <Bell className="h-5 w-5" />
  {count > 0 && (
    <span className="absolute top-1 right-1 bg-red-500 text-white text-[10px] font-semibold
                     rounded-full w-4 h-4 flex items-center justify-center leading-none">
      {count > 9 ? '9+' : count}
    </span>
  )}
</button>
```
- Badge hidden (not rendered) when count = 0
- Refetch interval: 60 seconds via `useQuery({ refetchInterval: 60_000 })`

### Student Grade Result View (SubmissionArea — extend existing)

**When `status === 'graded'`** (extend current graded branch in `SubmissionArea.tsx`):
- Badge: `bg-green-100 text-green-700` "Đã chấm" (already implemented)
- Submission photo thumbnail: `max-h-[200px]` + click opens full resolution in new tab (already implemented)
- Grade result box (already partially implemented — extend):
  ```
  <div className="p-3 bg-muted rounded-lg space-y-1">
    <p className="text-sm font-semibold">Điểm: {score}/10</p>
    {comment && <p className="text-sm text-muted-foreground">{comment}</p>}
  </div>
  ```
- Fire-and-forget `student_viewed_at` update on mount when `status === 'graded' && !student_viewed_at`

## Accessibility Contract

- All buttons `min-h-[48px] min-w-[48px]` — satisfies UX-02
- Bell button: `aria-label="Thông báo chấm bài"` + `aria-live="polite"` on badge span
- Dialog uses Radix `Dialog` — keyboard navigation, focus trap, ESC to close built-in
- Score input: `aria-label="Điểm số"` + visible label
- Comment textarea: `aria-label="Nhận xét"` + visible label
- Image `alt="Bài làm đã nộp"` — already in SubmissionArea
- Table `<TableHead>` cells provide column headers for screen readers

## Mobile Contract (375px viewport)

- Teacher queue table: `overflow-x-auto` wrapper — horizontal scroll on narrow viewport (consistent with UsersPage)
- GradingDialog: full-screen-width on mobile (`sm:max-w-lg` Dialog default; full on xs)
- Bell badge: absolute positioned, does not overflow header bounds
- StudentLayout header `h-12` (48px) with bell + logout fitting in `ml-auto flex items-center gap-2`
