## Critical Gaps

### 1. ROLE-03 — Student Data Isolation RLS (UNSATISFIED)

**Requirement:** RLS policies trong Supabase ngăn học sinh xem dữ liệu của nhau

**Status:** Never implemented. Phase 2 VERIFICATION.md marks it ORPHANED — listed in Phase 2 requirements but claimed by no plan. No SQL migration, no RLS policy file exists for profiles table student isolation.

**What exists:** Phase 3 added `is_admin()` and `is_approved_user()` SECURITY DEFINER helpers plus RLS policies for `courses`, `chapters`, `lessons`, and `enrollments` tables. But `profiles` table policies preventing a student from querying another student's row are absent.

**Impact:** Any authenticated student can query `SELECT * FROM profiles` and see other users' email, phone, name, and approval status.

---

### 2. Teacher Role — No Accessible Routes (CRITICAL INTEGRATION GAP)

**Affects:** ROLE-01, ROLE-02, GRADE-01, GRADE-02, GRADE-03

**Status:** Integration failure. Teacher role is defined in `src/types/auth.ts` and `ProtectedRoute` accepts `requiredRole="teacher"`, but:
- No route in `App.tsx` uses `requiredRole="teacher"`
- All grading routes use `requiredRole="admin"`
- `Header.tsx` shows no CTA for teacher role (only student / admin CTAs)

A user with `profile.role = 'teacher'` logs in → lands on landing page → has no navigation to grading → any attempt to reach `/admin/submissions` is redirected to `/`

**Fix:** Either (a) add teacher-specific routes with `requiredRole="teacher"`, or (b) update `ProtectedRoute` to accept multi-role arrays and add teacher to the admin grading routes.

## Moderate Issues

### AUTH-04 — Pending Student Redirect on Login

`Login.tsx` calls `navigate('/')` unconditionally after successful auth. A pending student who logs in lands on the static landing page with no indication of their pending state. They only see `/pending` if they attempt to navigate to a guarded route.

**Fix:** After login success, check `profile.approval_status` and redirect accordingly:
- `approved` + `student` → `/courses`
- `approved` + `admin` → `/admin/users`
- `pending` or `rejected` → `/pending`

### AUTH-03 — No Logout in AdminLayout

`AdminLayout.tsx` sidebar has no logout button. An admin can only log out by returning to the landing page. `StudentLayout` and `Header` correctly expose logout — admin area was missed.
